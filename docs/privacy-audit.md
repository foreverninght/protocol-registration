# 公开源码隐私复核

本轮针对页面填写示例、默认设置、测试数据、工具帮助文本、Git 历史和源码归档重新检查。此前仅清理真实姓名及明显凭据还不充分：具体邮箱域名、服务域名和公网服务地址也曾出现在示例、默认值及测试中，本轮已移除这些非通用配置。本文不记录其原始值。

## 已完成的清理

- 页面域名、邮箱和URL示例使用保留测试域名或回环地址，不从使用者已保存的配置生成示例。
- 新邮箱域名和自建服务地址不再带入历史默认值；明确配置后的正常工作流保留。
- 协议工具未配置服务地址时提前停止对应步骤，不向隐式旧地址发送账号、令牌或管理密钥。
- 测试中的具体历史域名改为保留域；代理自测使用明确的fixture账号和proxy.example.test，保持特殊字符编码验证。
- 命令行交互帮助不再显示具体手机号，电话测试样本使用NANP保留的555-01xx号码。
- Git忽略规则增加私钥、常见账号/邮箱/代理导出文件和压缩包；源码归档继续采用白名单。
- 新的公开历史从清理后的源码快照建立，作者使用项目维护者的GitHub用户名及GitHub隐私邮箱；旧历史留在私有归档，不通过普通追加提交将旧值留在公开历史中。

## 核查边界

审查覆盖受Git跟踪的源码、文档、页面、测试和发布ZIP，包括FreePP及共享worker。独立复核未发现额外高置信度真实账号密码、代理认证密码、API密钥、个人邮箱或个人目录；通用OAuth client_id、官方服务端点和明确的合成测试令牌不按使用者凭据处理。未尝试登录任何账户或连接候选代理来验证其有效性。

回归约束包括：HTML placeholder/value 中的URL和邮箱示例仅使用保留域或回环地址；个人服务目的地默认空；明确配置能被保留；缺少服务配置时不调用网络。原始排查记录及历史Git元数据不进入公开源码包。

这些结论适用于本次检查的源码与归档，不是对所有未知编码或未来修改的绝对保证。已经被其他人下载或外部缓存的旧副本不由本仓库的历史重建收回。运行时账号、邮箱和代理仍保存于使用者自己的数据库与本地配置中，不随源码发布。

## 本轮验证

清理后286项Node测试全部通过，使用真实本机PostgreSQL，零跳过；26项Python测试通过。浏览器的代理池、邮箱批量操作、并发与附加步骤设置、凭据复制及失败恢复验收通过，页面错误、失败请求和外部请求均为零。

另以未公开的检查脚本对受跟踪文件及本次新增文件复查已知个人标识和旧地址，无残留匹配；公开测试只使用正向示例规则，不收录原值或其黑名单。最终归档逐文件与源码及SHA256SUMS核对。
