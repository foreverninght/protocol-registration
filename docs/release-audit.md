# 开源前审核

审核日期：2026-10-08。本文件记录公开发布前的审核结果：本地单协议批量工作流及干净Windows部署核验通过，第三方许可核验存在下述未确认事项。后续维护者决定参照FreePP采用公开源码研究项目形式发布，保留来源与原有声明，不新增整包统一许可证；该发布决定不改变已有测试结果或补充上游授权证明。

## 最终核验

- 281项Node测试全部通过，真实本机PostgreSQL，零失败、零跳过；批量与租约测试使用隔离数据库，避免其它测试服务的队列轮询影响。
- 24项Python协议、依赖和归档测试，以及71项共享worker测试通过；JavaScript语法检查通过。
- 浏览器实际验证主/资格代理池增删改查及URL导入去重、邮箱导入去重及批量删除、并发设置与附加步骤保存、批量凭据复制、失败后恢复及缺失TOTP的导出限制。页面错误、失败HTTP请求和外部请求均为零。
- 15份数据库迁移首次执行和重复执行通过，临时数据库停止并清理。
- 独立Windows解包副本：清空安装目录后离线npm ci通过；全新隔离venv安装及pip check通过；真实main/server模块导入与配置加载通过，依赖路径均来自该干净副本。该副本无DB运行结果为247项通过、34项按条件跳过；实际数据库覆盖由上一项提供。
- setup重复执行保持.env哈希不变；旧配置没有新增来源变量时仍保持默认本机行为。
- 运行环境实测为Node22.22.2、npm10.9.7、Python3.13.12。Docker CLI缺失，Compose及Linux/macOS未实跑，不作已验证声明。
- 本轮对最终Node锁文件执行公开npm audit，返回0项已知漏洞；这是本次数据库查询结果，不是永久无漏洞保证。

注册上游HTTP和邮箱响应在自动化回归中使用可控替身；未进行真实外部账号注册。因此已证明本地调度、IPC、数据库、界面和恢复链路，不据此声明实时线上成功率。

## 公开发布前仍需确认

维护者自有平台与worker实现应由维护者确认许可，不笼统列为第三方。需进一步核实的是FreePP以及worker中实际引用的代码、Sentinel捆绑/重建资源，详见[THIRD_PARTY.md](../THIRD_PARTY.md)中对上游README和源码的最新核查。未擅自给整包授予MIT或其它许可证。SDK哈希、源码可下载以及运行通过都不替代再分发许可。

Python传递依赖及制品哈希尚未完整锁定；已证明一次干净安装，不声明未来安装逐字节复现。当前工作台供可信本地操作者使用，没有内建多用户鉴权；远程开放需由部署者配置身份认证和TLS。

脱敏覆盖已知事件格式和文本产物，不声称扫描穷尽全部秘密；历史Evidence不在本次迁移清洗范围，二进制图片未做内容识别。已有账号若缺少历史换绑邮箱的私有取码上下文，会明确报路由缺失，不读取旧邮箱。进程强制退出仍有远端操作与本地落库之间的恢复边界。

本轮没有修改生产服务、配置或数据库，没有操作原FreePP工作目录，没有提交或推送仓库。最终归档以白名单及SHA256SUMS交叉核验，排除.env、运行数据、日志、缓存、依赖安装目录和虚拟环境。
